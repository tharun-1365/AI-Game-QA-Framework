# AI Game QA Framework

An AI-powered automated game testing and gameplay analysis framework built in Unity 6.

## Features
- Automated gameplay testing
- Deterministic test environments
- Telemetry collection
- Behaviour analysis
- AI-assisted bug detection (planned)

## Tech Stack
- Unity 6.3 LTS
- C#
- Unity Test Framework

## Roadmap
- ✅ Milestone 1 – Baseline environment
- ⏳ Milestone 2 – Telemetry & input recording
- ⏳ Milestone 3 – Automated test runner
- ⏳ Milestone 4 – Behaviour analysis
- ⏳ Milestone 5 – AI-driven QA pipeline
